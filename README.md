# Mohamed | Portfolio & Creative Showcase

A modern, responsive portfolio and showcase website deployed on **GitHub Pages**.

## 🚀 Features
- **Tailwind CSS & Lucide Icons** for a sleek, glassmorphism UI.
- **Dark / Light Mode** toggle with auto system preference detection.
- **Interactive UI components** and responsive mobile layout.
- **Fast Static Hosting** via GitHub Pages.

## 📦 How to Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repository-name>/`.
